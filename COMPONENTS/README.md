# Componentes visuais do Catecismo

Esta pasta guarda as artes-fonte originais. Mantenha esses arquivos intactos; as versões incluídas no app ficam em `iosApp/Resources/Images/` e são reduzidas/otimizadas para limitar o tamanho do download.

## Arte do ícone

- `CATECISMO IGREJA CATOLICA LOGO.png` é a arte completa escolhida para o ícone iOS. As cópias em `iosApp/Resources/Assets.xcassets/AppIcon.appiconset/` usam a imagem inteira, redimensionada para os tamanhos exigidos.
